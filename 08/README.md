# Лабораторная работа 8

## Реализация функциональности оформления заказа

### Основные изменения:

1. **Сохранение выбранных блюд в localStorage**
   - Все выбранные блюда сохраняются в localStorage при изменении
   - В localStorage хранятся только ID блюд
   - При загрузке страницы заказ восстанавливается из localStorage

2. **Страница "Оформить заказ" (checkout.html)**
   - Раздел "Состав заказа" - отображает выбранные блюда с возможностью удаления
   - Раздел "Оформление заказа" - форма для ввода данных клиента
   - При удалении блюда из состава заказа, оно также удаляется из формы

3. **Модификация страницы "Собрать ланч" (lunch.html)**
   - Убрана форма оформления заказа
   - Добавлена панель перехода к оформлению (sticky)
   - Панель показывает текущую стоимость заказа
   - Ссылка "Перейти к оформлению" активна только при валидном составе заказа

4. **Отправка заказа на сервер**
   - Используется API лабораторной работы 8
   - Все запросы содержат параметр `api_key` в строке запроса
   - При успешной отправке заказа localStorage очищается
   - При ошибке localStorage сохраняется

### Важно:

**Перед использованием необходимо заменить API_KEY в файле `checkout.js`:**
```javascript
const API_KEY = 'YOUR_API_KEY_HERE'; // Замените на ваш реальный API ключ
```

API ключ можно получить по ссылке из СДО Московского Политеха.

### Структура файлов:

- `index.html` - главная страница (обновлена навигация)
- `lunch.html` - страница "Собрать ланч" (с панелью перехода)
- `checkout.html` - страница "Оформить заказ"
- `contacts.html` - страница контактов (обновлена навигация)
- `orders.html` - страница заказов (обновлена навигация)
- `dishes.js` - загрузка блюд через API
- `storage.js` - работа с localStorage
- `render.js` - логика страницы "Собрать ланч"
- `checkout.js` - логика страницы "Оформить заказ"
- `style.css` - стили (добавлены стили для панели перехода)

### API Endpoints:

- `GET /labs/api/dishes` - получить список всех блюд
- `GET /labs/api/dishes/{id}` - получить данные конкретного блюда
- `POST /labs/api/orders?api_key={key}` - создать новый заказ

### Формат данных в localStorage:

```json
{
  "soup_id": 1,
  "main_id": 8,
  "salad_id": 16,
  "drink_id": 19,
  "dessert_id": null,
  "ready_variant_price": 750
}
```
